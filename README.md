# a9m-livestream-control-plane
Control Plane điều phối CDN: GSLB định tuyến người xem đến Edge tối ưu dựa trên IP và tải Redis; Auth &amp; Token Signer xác thực, ký URL HMAC/JWT; GPU Orchestrator tự động bật/tắt GPU theo sự kiện Publish/Unpublish; Edge Health Monitor giám sát băng thông và CCU của 3 cụm Edge theo thời gian thực.
